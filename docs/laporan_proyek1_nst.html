1. Pendahuluan & Pembagian Peran Tim

1.1 Latar Belakang dan Tujuan Proyek

Neural Style Transfer (NST) merupakan teknik sintesis citra berbasis pembelajaran mendalam yang memadukan struktur konten semantik dari sebuah citra foto (content image) dengan tekstur, sapuan kuas, serta palet warna artistik dari citra lukisan (style image). Berbeda dari pelatihan jaringan saraf konvensional yang memperbarui bobot model, NST mempertahankan seluruh bobot jaringan ekstraktor fitur VGG-19 dalam kondisi beku (frozen) dan melakukan optimasi iteratif langsung terhadap nilai piksel tensor citra target.

Pada Proyek 1 ini, tim membangun sistem NST secara modular dari nol (from scratch) menggunakan PyTorch tanpa memakai fungsi pembungkus instan seperti nn.MSELoss, F.mse_loss, ataupun pustaka NST siap pakai. Seluruh operasi matematis inti—mulai dari normalisasi ImageNet, pemotongan feature extractor VGG-19, perhitungan Gram Matrix, Content Loss, Style Loss, hingga loop optimasi piksel dengan pencatatan metrik terstruktur—diimplementasikan secara eksplisit dan diverifikasi melalui pengujian unit maupun eksperimen penuh pada GPU CUDA.

2. Strategi Vibe Coding & Alur Kolaborasi Git

2.1 Strategi Vibe Coding Berbasis Kontrak Modular

Dalam pendekatan Vibe Coding, asisten LLM diposisikan sebagai mitra pemrograman yang bekerja berdasarkan kontrak antarmuka yang ketat dan terverifikasi per modul, bukan generasi kode monolitik sekaligus. Tim menerapkan lima prinsip utama sepanjang pengembangan:

  1. Isolasi Sesi per Modul (One Chat per Module): Setiap modul dikerjakan pada sesi percakapan terpisah (3 modul untuk Danendra, 4 modul/tahap untuk Naufal) dengan konteks batas kepemilikan file yang eksplisit agar agen LLM tidak memodifikasi modul milik rekan tim.
  2. Kontrak Antarmuka Terpusat di config.py: Seluruh konstanta penting disepakati sejak awal: parameter normalisasi IMAGENET_MEAN dan IMAGENET_STD, resolusi FAST_IMAGE_SIZE = (192, 256) untuk uji cepat dan FINAL_IMAGE_SIZE = (384, 512) untuk run final, pemetaan indeks VGG19_LAYER_MAP, dictionary output dict[str, torch.Tensor] berdimensi (B, C, H, W), serta skema kolom metrics.csv (step,total_loss,content_loss,style_loss,elapsed_sec).
  3. Pengembangan Paralel dengan Mekanisme Fallback & Optional Integration: Ketika Anggota 2 membangun data/preprocessing.py dan models/losses.py sebelum branch Anggota 1 digabungkan ke main, impor config.py dibungkus blok try ... except ImportError dengan nilai fallback identik. Sebaliknya, tests/smoke_test.py milik Anggota 1 menggunakan inspeksi tanda tangan fungsi (_find_callable dan _call_with_accepted_kwargs) serta penandaan [SKIP] terkendali apabila modul Anggota 2 belum ada di branch kerja.
  4. Dokumentasi Dimensi Tensor & Verifikasi Segera: Setiap transformasi tensor pada kode wajib disertai komentar perubahan dimensi (misalnya (B, C, H, W) -> (B, C, H * W) -> (B, C, C)), dan setiap modul dilengkapi blok uji mandiri (__main__) atau skrip uji yang dijalankan langsung melalui .\.venv\Scripts\python.exe.
  5. Keterlacakan Prompt, Eror, dan Solusi: Seluruh interaksi penting dirangkum ke dalam docs/logs/log_danendra.md dan docs/logs/log_naufal.md serta diekspor utuh ke docs/chats/ sebagai jejak audit pengembangan.

Pada modul data/preprocessing.py, setiap gambar diproses melalui fungsi load_image(path, image_size, device) dengan urutan transformasi sebagai berikut:

  1. Membuka berkas gambar memakai Pillow dan melakukan konversi paksa ke ruang warna 3-kanal RGB untuk menghindari eror dimensi kanal (seperti RGBA atau grayscale).
  2. Mengubah ukuran citra secara seragam ke format landscape (H, W) = (384, 512) (FINAL_IMAGE_SIZE; atau (192, 256) pada mode cepat FAST_IMAGE_SIZE) menggunakan filter interpolasi LANCZOS.
  3. Mengonversi citra ke array NumPy float32 yang diskalakan ke rentang [0.0, 1.0], mengubah susunan dimensi dari (H, W, 3) menjadi (3, H, W) via permute(2, 0, 1), lalu menambahkan dimensi batch sehingga menjadi (1, 3, H, W).
  4. Menerapkan normalisasi standar ImageNet per kanal menggunakan IMAGENET_MEAN = (0.485, 0.456, 0.406) dan IMAGENET_STD = (0.229, 0.224, 0.225) melalui broadcasting tensor (1, 3, 1, 1):
xnorm,c = (xc − μc) / σc,    c ∈ {R, G, B}
(1)

Sebaliknya, untuk mengonversi hasil optimasi kembali menjadi citra yang dapat disimpan, fungsi deprocess_image(tensor) melepaskan tensor dari graf autograd (detach().cpu().clone()), mengembalikan distribusi piksel dengan operasi img * std + mean, membatasi nilai ke rentang valid [0.0, 1.0] via torch.clamp, dan mengubah susunan dimensi kembali ke (H, W, 3) sebelum dikonversi menjadi uint8 [0, 255] oleh save_image.

3.2 Ekstraktor Fitur VGG-19 Beku (models/vgg_extractor.py)

Kelas VGGFeatureExtractor(nn.Module) memanfaatkan arsitektur torchvision.models.vgg19 dengan bobot pretrained VGG19_Weights.DEFAULT. Alih-alih memuat seluruh blok klasifikasi hingga fully connected layer, ekstraktor hanya memotong bagian vgg19.features hingga indeks layer terdalam yang dibutuhkan (max_layer_idx + 1, yakni indeks 0..28 atau total 29 sub-layer sampai conv5_1) sehingga konsumsi memori lebih hemat dan eksekusi lebih cepat baik di CPU maupun CUDA.

Tiga pengamanan krusial diterapkan dalam VGGFeatureExtractor:

  • Nonaktifkan inplace pada nn.ReLU: Seluruh modul nn.ReLU di dalam potongan features diatur menjadi layer.inplace = False agar aktivasi Conv2d yang disimpan ke dictionary tidak tertimpa secara in-place sebelum proses backpropagation selesai.
  • Pembekuan Bobot: Seluruh parameter pada self.features.parameters() diatur requires_grad = False sehingga tidak ada gradien yang dihitung untuk bobot VGG-19.
  • Penguncian Mode eval(): Konstruktor memanggil super().eval() dan metode train(self, mode=True) di-override untuk selalu memanggil super().train(False), menjamin perilaku ekstraktor tetap deterministik meskipun dipanggil model.train(True).

3.3 Implementasi Manual Gram Matrix dan Fungsi Loss (models/losses.py)

Seluruh komponen loss ditulis secara manual menggunakan operasi tensor dasar PyTorch (reshape, transpose, torch.bmm, pengurangan, pengkuadratan ** 2, dan torch.mean) tanpa memanggil fungsi loss tingkat tinggi.

A. Gram Matrix Ternormalisasi (compute_gram_matrix)

Untuk menangkap korelasi statistik antar-kanal filter tanpa bergantung pada posisi spasial absolut, feature map 4D berdimensi (B, C, H, W) diratakan menjadi matriks F berukuran (B, C, H·W), dikalikan dengan transposenya FT berdimensi (B, H·W, C) via torch.bmm menghasilkan (B, C, C), lalu dinormalisasi terhadap total elemen aktivasi C · H · W:

Gij(l) = (1 / (Cl · Hl · Wl)) ∑k=1..HlWl Fik(l) Fjk(l)
(2)

B. Content Loss (compute_content_loss)

Content Loss mengukur kedekatan struktur spasial citra target P terhadap citra konten C pada layer conv4_2 melalui Mean Squared Error manual:

Lcontent(P, C) = mean( (Ftarget(conv4_2) − Fcontent(conv4_2))2 )
(3)

C. Style Loss (compute_style_loss)

Style Loss menghitung akumulasi terbobot selisih kuadrat rata-rata antara Gram Matrix citra target Gtarget(l) dan Gram Matrix citra gaya Gstyle(l) pada lima layer gaya S = {conv1_1, conv2_1, conv3_1, conv4_1, conv5_1} dengan bobot seragam wl = 0,2:

Lstyle(P, S) = ∑l ∈ S wl · mean( (Gtarget(l) − Gstyle(l))2 ),    wl = 0,2
(4)

D. Total Loss (compute_total_loss)

Kombinasi linier antara pelestarian konten (α) dan transfer gaya (β) menghasilkan fungsi objektif total yang dikembalikan bersama komponen individualnya sebagai tuple (total_loss, content_loss, style_loss):

Ltotal = α · Lcontent + β · Lstyle
(5)
Hasil Verifikasi Unit Test & Smoke Test: Pengujian mandiri models/losses.py pada CUDA membuktikan bentuk Gram Matrix tepat (2, 128, 128) dan simetris, nilai content_loss dan style_loss sama dengan 0.00e+00 saat fitur target identik, total_loss = 2.0995 (content = 2.0213, style = 0.000001) saat fitur berbeda, dan total_loss.backward() menghasilkan gradien valid bebas NaN/Inf. Skrip tests/smoke_test.py juga terverifikasi sukses pada CPU maupun CUDA (frozen=True, eval_locked=True).

3.4 Loop Optimasi End-to-End (train.py)

Skrip CLI train.py mengintegrasikan config.py, data/preprocessing.py, models/vgg_extractor.py, dan models/losses.py dalam alur optimasi piksel berikut:

  1. Ekstraksi Fitur Referensi: content_img dan style_img dilewatkan ke VGGFeatureExtractor di dalam blok with torch.no_grad(): dan dilepas memakai .detach() agar graf komputasi referensi tidak tersimpan saat iterasi.
  2. Inisialisasi Tensor Target: Fungsi initialize_target membuat tensor daun graf autograd target berdimensi (1, 3, H, W) dengan requires_grad_(True), baik berupa kloning citra konten (--init content, default) maupun derau Gaussian acak (--init noise).
  3. Konfigurasi Optimizer Khusus Piksel: Fungsi build_optimizer mendaftarkan hanya [target] ke optimizer Adam (default lr = 0.02) atau L-BFGS (max_iter = 1 dengan pola closure()).
  4. Iterasi Optimasi & Pencatatan Artefak: Pada setiap step 1..steps, helper _compute_step_losses() melakukan optimizer.zero_grad(), ekstraksi target_features = extractor(target), perhitungan compute_total_loss, dan total_loss.backward() sebelum optimizer.step(). Nilai step, total_loss, content_loss, style_loss, elapsed_sec dicatat ke metrics.csv di tiap step, snapshot berkala disimpan tiap --save_every step bila diaktifkan, dan di akhir pelatihan citra target disimpan ke result.png bersama metadata run_config.json.

# Normalisasi ImageNet per channel: (1, 3, H, W) -> (1, 3, H, W)
